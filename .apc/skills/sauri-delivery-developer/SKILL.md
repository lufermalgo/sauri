# Developer delivery

- Read the assigned card, approved behavior, worktree, validation commands and applicable gates. Load the named project skills. Resolve missing facts from their source; escalate decisions or blockers to Ansel.
- Own one candidate in the isolated worktree. Keep RED → GREEN → REFACTOR together and run affected real tests and configured checks. Do not duplicate execution by chat or weaken tests.
- Publish the exact candidate and draft PR. Record SHA, commands, evidence, limitations and next reviewer on the card. Fix blockers and revalidate impacted gates only. Ansel merges.
- Follow WORKFLOW §§4–9 and the approved UI language. For UI work, compare against the applicable captures and report deviations; do not invent excluded scope.
